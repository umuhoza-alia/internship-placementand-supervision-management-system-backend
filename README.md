## Project Description
This project is a Spring Boot REST API for managing internship placements and supervision. It manages interns, supervisors, host companies, internship fields, placements, and evaluations.

## Technologies Used
- Java 25
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Postman

## Database Setup
1. Create a PostgreSQL database named `internship_db`.
2. Configure the database connection in `application.properties`.
3. Set the database password using the `DB_PASSWORD` environment variable.

## How to Run the Application
1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Configure the PostgreSQL database connection.
4. Open the terminal in the project folder.
5. Run:
